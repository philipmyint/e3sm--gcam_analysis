   13      Each new synthetic time series in the ensemble is output into a .dat or .csv file.

   20                  The fifth item is the total number of time series (including the base time series) we want to include in the set.

   30      # Subtract by 1 because the base time series is already included in the file.
   31      num_synthetic_sets_in_ensemble = inputs[4] - 1

   33      df_ensemble = df.copy()

   35      # Iterate through each scenario and produce the specified number of variations for each scenario.

   41              multipliers = base_multipliers[set_index] + random_multipliers
   42              df_new[columns_to_modify] = df_this_scenario[columns_to_modify].multiply(multipliers, axis='index')
   43              # Start numbering the new synthetic time series from 2 onwards to avoid confusion with the base time series.
   44              df_new[scenario_label] = f'{scenario}_{set_index+2}'
   45              df_ensemble = pd.concat([df_ensemble, df_new], axis=0)
